# Borozdov Scholar

A theme from the Borozdov collection. Two faces — light **Vellum**, a scholar's desk on warm
paper, and dark **Study**, the same desk after the lamps come on. Quiet hairlines, calm
400–500 type, soft 16px cards and one deep teal for what you choose.

![Borozdov Scholar in light mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/scholar/main/screenshots/light.png)

![Borozdov Scholar in dark mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/scholar/main/screenshots/dark.png)

## Principles

- **Paper first.** A warm parchment page, cards one step above it, hairline rules instead
  of shadows; nothing is pure white.
- **One teal.** Deep teal fills what you choose — checked tasks, toggles, the main button,
  the selected file — and colors links and the caret. Nothing else is chromatic.
- **Quiet type.** The platform's own sans between 400 and 500; headings are a size step,
  not a weight step, and bold is a gentle 600.
- **Soft shapes.** 16px cards, 12px fields, 6px ghost buttons, pill chips for tags.

## Features

- Light and dark modes, following Settings → Appearance → Base color scheme
- Compact callouts as cards with a hairline edge; the title in the type's color
- Code on a paper card with a hairline; tables with a rounded hairline frame and grid
- Tags as rim-only chips
- Quiet editing: no focus ring around the note, its title or form fields while you type;
  property names read as labels, not boxed fields
- Text colors meet WCAG contrast on both faces
- The phone layout keeps the same colors and shapes
- No fonts embedded and no `!important`: about 13 KB, every rule overridable with a
  CSS snippet

## Installation

**From the community directory:** Settings → Appearance → Themes → Manage, search for
**Borozdov Scholar**, then **Install and use**.

**By hand:** download `manifest.json` and `theme.css` from the
[latest release](https://github.com/borozdov-obsidian-themes/scholar/releases/latest) into
`<vault>/.obsidian/themes/Borozdov Scholar/`, then choose Borozdov Scholar under
Settings → Appearance → Themes.
